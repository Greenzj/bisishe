⚙️ Supabase 数据库配置指南

在使用之前，需要在 Supabase 中创建以下数据表。请按步骤操作：

1️⃣ 创建 Supabase 项目

访问 supabase.com，注册并创建免费项目。

2️⃣ 获取配置信息

在项目设置 → API 中，复制 Project URL 和 anon public key，替换上方代码中的 SUPABASE_URL 和 SUPABASE_ANON_KEY。

3️⃣ 创建数据表（在 SQL Editor 中执行）

-- Groups table
CREATE TABLE groups (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  invite_code TEXT UNIQUE NOT NULL,
  created_by TEXT NOT NULL,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Members table
CREATE TABLE members (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  group_id UUID REFERENCES groups(id) ON DELETE CASCADE,
  nickname TEXT NOT NULL,
  is_admin BOOLEAN DEFAULT FALSE,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Records table
CREATE TABLE records (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  group_id UUID REFERENCES groups(id) ON DELETE CASCADE,
  member_id UUID REFERENCES members(id) ON DELETE CASCADE,
  nickname TEXT NOT NULL,
  check_date DATE NOT NULL,
  today_done TEXT NOT NULL,
  tomorrow_plan TEXT NOT NULL,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Enable RLS but allow all for simplicity (10-person group)
ALTER TABLE groups ENABLE ROW LEVEL SECURITY;
ALTER TABLE members ENABLE ROW LEVEL SECURITY;
ALTER TABLE records ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Allow all on groups" ON groups FOR ALL USING (true);
CREATE POLICY "Allow all on members" ON members FOR ALL USING (true);
CREATE POLICY "Allow all on records" ON records FOR ALL USING (true);

4️⃣ 修改配置并启动

将上面的 SQL 在 Supabase SQL Editor 中执行，然后修改本文件顶部的 SUPABASE_URL 和 SUPABASE_ANON_KEY，即可开始使用！
